# Анализ и подготовка данных для трёх бизнес-задач

В этой работе я сделала цикл предварительного анализа данных для трёх наборов данных из разных предметных областей.

1. **Students Performance** образование
2. **Starbucks Stock Price** финансы 
3. **World Population** демография   

Для каждого датасета сформулированы бизнес-цели, проведена предобработка данных, разбиение на выборки, оценка сбалансированности, применены методы аугментации данных.

## Решаемые бизнес-задачи
**Students Performance**: Оптимизировать образовательные программы на основе факторов успеваемости.
**Starbucks Stock**: Построить модель прогнозирования цен акций для алгоритмической торговли.
**World Population**: Спрогнозировать спрос на ресурсы и услуги на основе демографических трендов.

## Ключевые этапы
1. Предобработка данных 
- Очистка от нечисловых символов
- Замена пропусков (медиана, мода)
- Преобразование категориальных признаков в числовые
- Извлечение числовых значений из текстовых полей
- Удаление аномальных выбросов

2. Разбиение на выборки
Для каждого датасета данные были разделены на *обучающую (70%)*, *контрольную (15%)* и *тестовую (15%)* выборки с учётом:
- Стратификации по целевому признаку (для классификации)
- Сохранения временного порядка (для финансовых временных рядов)

3. Оценка сбалансированности
- **Students Performance**: дисбаланс классов по уровням успеваемости, применён oversampling и undersampling.
- **Starbucks Stock**: данные сбалансированы по распределению цен, применён undersampling для уменьшения объёма.
- **World Population**: из-за малого числа записей применён oversampling с добавлением шума.

4. Наблюдения
- Students Performance: высокая корреляция между оценками по предметам, это потенциальная утечка данных при прогнозировании.
- Starbucks Stock: цена закрытия сильно зависит от предыдущих значений.
- World Population: данные идеально линейны, но объём слишком мал для сложных моделей.

5. Визуализация

По каждому датасету построены:

- Гистограммы распределения целевой переменной
- Boxplot для выявления выбросов
- Графики корреляции признаков (тепловые карты)

## Данные
1. Датасет Students Performance in Exams: https://www.kaggle.com/datasets/spscientist/students-performance-in-exams
2. Датасет Starbucks Stock Price Dataset: https://www.kaggle.com/datasets/mayankanand2701/starbucks-stock-price-dataset
3. Датасет World Population: https://www.kaggle.com/datasets/muhammedtausif/world-population-by-countries
