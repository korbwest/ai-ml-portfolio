# Базовые навыки работы с табличными данными и первичный анализ на датасете объявлений о продаже автомобилей. 

## Ключевые навыки:
- Pandas (Манипуляции с данными): загрузка/сохранение (read_csv, to_csv), инспекция (info, dtypes), срезы и индексация (iloc), группировка и агрегация (groupby, mean, count), сортировка (sort_values).
- Data Cleaning (Очистка данных): обработка пропусков (fillna, dropna), удаление нерелевантных признаков (drop), базовый Feature Engineering (создание бинарного признака Is_Expensive на основе условия).
- Визуализация (Matplotlib / Pandas.plot):
- Line plot: анализ средней стоимости авто в разрезе годов выпуска.
- Scatter plot: оценка корреляции и распределения цены в зависимости от пробега.
- Pie chart: анализ рыночных долей автомобильных брендов.

## Данные
Датасет Car Price Prediction Challenge: https://www.kaggle.com/datasets/deepcontractor/car-price-prediction-challenge
