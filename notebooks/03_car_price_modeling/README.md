# Решение задач регрессии и классификации на основе данных о продаже подержанных автомобилей

## Решаемые бизнес-задачи
- Регрессия: Точное прогнозирование рыночной стоимости автомобиля (Price) на основе его технических и визуальных характеристик.
- Классификация: Сегментация автомобилей на ценовые категории (Бюджетный, Средний, Премиум) для целей маркетинга и аналитики рынка.

## Метрики качества
Ориентиры и целевые метрики
- Регрессия:
1. R^2 (качество объяснения данных моделью) 0.6 - 0.7
2. MAE (средняя абсолютная ошибка), 2000-5000

- Классификация: 
1. Accuracy. (Аккуратность, доля верных ответов) > 61%
2. F1-score. (Сбалансированность ответов) > 0.70

## Ключевые этапы
1. Парсинг и очистка: Извлечение числовых значений из строк.
2. Преобразование данных: Колонка Doors содержала некорректные данные (например, 02-Mar вместо 2-3).
3. Создание новых признаков: Разделение Engine volume на числовой объем и бинарный флаг наличия турбины (Turbo).
4. Расчет возраста автомобиля (Age) на основе года производства.
5. Для обеспечения чистоты эксперимента и предотвращения утечки данных использовано заполнение пропусков медианой + стандартизация для числовых признаков и заполнение пропусков модой и One-Hot Encoding для категориальных.

## Бизнес-применимость
- Модель Random Forest Regressor позволяет оценивать стоимость авто с средней ошибкой в $4408, что делает её пригодной для использования в качестве вспомогательного инструмента для автодилеров или на онлайн-площадках.
- Модель Random Forest Classifier с точностью 80% автоматически размечает автомобили по сегментам, что может быть использовано для таргетированной рекламы или формирования рекомендательных систем.
