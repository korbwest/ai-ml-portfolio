# Решение задачи кластеризации на основе данных о продаже подержанных автомобилей

## Решаемая бизнес-задача
Выявить скрытые «профили» автомобилей (например, комфортный городской седан, семейный внедорожник, бюджетный рабочий транспорт) для оптимизации маркетинговых стратегий, управления складскими запасами или построения рекомендательных систем.

## Ключевые этапы
1. Предобработка данных:
- Очистка и преобразование признаков (извлечение числового объема двигателя и флага Turbo, парсинг пробега и количества дверей).
- Кодирование категориальных признаков с помощью OneHotEncoder.
- Масштабирование числовых признаков с помощью StandardScaler.

2. Снижение размерности:
- Применение PCA (Principal Component Analysis) для визуализации многомерного пространства признаков в 2D.

3. Выбор оптимального числа кластеров:
- Оценка с помощью Метода локтя и Коэффициента силуэта.
- Оптимальное количество кластеров выбрано как k=3 на основе максимизации коэффициента силуэта.

4. Применение алгоритмов кластеризации: KMeans и Agglomerative Clustering (Иерархическая)

5. Построение дендрограммы для визуализации иерархии слияния.

6. Интерпретация результатов и профилирование:
Анализ наиболее частых значений категориальных признаков внутри каждого кластера для формирования понятных бизнес-профилей.

## Бизнес применимость
Несмотря на то, что метрика силуэта оказалась низкой (что говорит о естественном перекрытии кластеров в признаковом пространстве, так как один автомобиль может сочетать признаки разных сегментов), алгоритмы позволили выделить интерпретируемые группы.
- Кластер 0: Sedan + TOYOTA + Petrol + Leather: Yes + Automatic. Профиль: Надежный, комфортабельный городской автомобиль для ежедневных поездок.
- Кластер 1: Jeep + HYUNDAI + Diesel + Leather: Yes + Automatic. Профиль: Семейный или загородный кроссовер/внедорожник с высоким уровнем комфорта.
- Кластер 2: Jeep + NISSAN + Diesel + Leather: No + Manual. Профиль: Бюджетный, утилитарный внедорожник. Ценится за проходимость и экономичность (возможно, использование в качестве рабочего транспорта или такси).
