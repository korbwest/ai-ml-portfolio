## 02. [Анализ данных из 3 предметных областей](./notebooks/02_analysis_and_preparation/02_analysis_and_preparation.ipynb/)
- **Цель**: проанализировать 3 набора данных, провести предобработку данных и поставить бизнес-задачу для каждого датасета.
- Очистка и Feature Engineering:
- Парсинг числовых значений из текстовых полей и удаление артефактов форматирования.
- Кодирование категориальных переменных и создание новых информативных признаков.
- Корректное разделение данных на выборки:
Пропорции: 70% (train) / 15% (validation) / 15% (test).

Адаптивный выбор стратегии: применение Oversampling или Undersampling в зависимости от специфики распределения целевой переменной в каждом конкретном датасете.
- Визуальный анализ (EDA):
Построение тепловых карт корреляций, графиков для детекции аномалий и гистограмм распределения целевых признаков.

## 03. [Регрессия и Классификация](./notebooks/03_car_price_modeling/03_car_price_modeling.ipynb/)
- **Цель**: Построить ML-модели для предсказания цены автомобиля и его ценовой категории.
- **Задачи**:
- Регрессия: Предсказание цены (Price) → Лучшая модель: Random Forest (R² = 0.66, MAE = 4408)
- Классификация: Отнесение к ценовой категории (budget/medium/premium) → Лучшая модель: Random Forest (Accuracy = 80.3%, F1 = 0.80)
- **Ключевые особенности**:
- Полный Pipeline с предобработкой и моделью
- Feature Engineering: извлечение Turbo, Age, бинаризация признаков
- Сравнение 3 моделей для каждой задачи с обоснованием метрик

## 04. [Кластеризация](./notebooks/04_car_market_clustering/04_car_market_clustering.ipynb/)
- **Цель**: Выявить скрытые профили автомобилей для маркетинговой сегментации.
- **Методы**:
- PCA - снижение размерности и визуализация
- KMeans - неиерархическая кластеризация
- Agglomerative Clustering - иерархическая кластеризация с дендрограммой
- **Результаты**:
KMeans выделил 3 маркетингово-интерпретируемых сегмента:
1. Комфортный городской седан (Toyota, Petrol, Automatic)
2. Семейный кроссовер (Hyundai, Diesel, Leather)
3. Бюджетный внедорожник (Nissan, Diesel, Manual)
